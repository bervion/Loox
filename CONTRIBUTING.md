# Contributing to Loox

Thanks for helping. Loox is a password manager, so the bar for correctness, privacy and polish is high. This guide keeps your change easy to review and merge.

## Before you start

- **Bugs:** open an issue with deterministic steps and synthetic data. Never paste real vault contents, recovery keys or tokens.
- **Features and larger changes:** open an issue first so we can agree on the approach before you write code.
- **Security issues:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

## Set up

Follow [Building from source](README.md#building-from-source). In short:

```bash
mise install
mise exec -- tuist generate
```

The Xcode project is generated by Tuist from [`Project.swift`](Project.swift). Never commit `*.xcodeproj`, `*.xcworkspace` or `Derived/`. After adding, removing or renaming a file, run `mise exec -- tuist generate` again.

## Rules that reviews enforce

The full list lives in [CLAUDE.md](CLAUDE.md), which doubles as the contributor guide for humans and coding assistants. The essentials:

- **Localization.** Every user-facing string goes into `Vaultify/Localizable.xcstrings` with English, Vietnamese and Japanese values. Safari extension strings go into `VaultifySafari/Resources/_locales`.
- **Design system.** Screens compose tokens and components only: no hard-coded colors, fonts, spacing or shadows. Read [docs/design-guidelines.md](docs/design-guidelines.md) and check light, dark, Reduce Motion, Reduce Transparency and the longest localized label.
- **Icons.** Render icons through `VaultIcon`. Do not use `Image(systemName:)` directly, and do not add SF Symbols newer than iOS 17.3.
- **Platform floor.** iOS 17.3 and macOS 15. Guard newer APIs with `#available`.
- **Concurrency.** The project defaults to `MainActor` isolation. Mark crypto and data types `nonisolated` so heavy work stays off the main thread.
- **Privacy.** Analytics events come only from the typed catalog in `Vaultify/Analytics/` and never carry item names, values, websites or search terms. Extensions must never link Firebase.
- **Crypto.** Changes under `VaultifyCore/Crypto` or `VaultifyCore/CArgon2` need tests, including known-answer vectors where they apply.

## Test

```bash
mise exec -- make check                             # compile the app and extensions
mise exec -- make test TEST_TARGETS=VaultifyTests   # unit tests, the suite CI runs
```

Add or update tests with every behavior change. UI changes should include before and after screenshots in light and dark mode.

## Commits and pull requests

- Use [Conventional Commits](https://www.conventionalcommits.org): `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`.
- Keep a pull request focused on one change and target `main`.
- Describe what changed, why, and how you tested it.
